OIBSIP – Graphic Design Internship

Task 2: Café Logo Design

Project Name

Brew & Bloom Café

Objective

To create an original, simple, and professional logo for a fictional café brand using Canva.

Design Concept

The logo concept combines a coffee cup, steam, and a leaf. The coffee cup represents warmth and comfort, while the leaf represents freshness and nature.

Colour Palette

- Cocoa Brown: #4E342E
- Caramel: #D4A373
- Leaf Green: #6B8E23
- Cream: #F8F5EF

Tool Used

Canva

Deliverables

- Full-colour logo
- Black monochrome logo
- Reversed white logo
- PNG and SVG files, where available

Conclusion

This project demonstrates the basic principles of logo design, colour selection, typography, and brand identity.
